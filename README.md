# SppaseNASAproject
Інтерактивна 3D-демо про космічні апарати та обладнання, які людство залишило на Місяці та Марсі. Проєкт створено для хакатону NASA.

## Ідея

Люди відправили на Місяць і Марс десятки апаратів: посадкові модулі, марсоходи, наукові станції. 
Багато з них досі стоять там, де зупинилися. Наш проєкт дозволяє пройти шляхом цих об'єктів у хронологічному порядку, від найдавніших до найновіших.

## Як це працює

1. Користувач запускає програму і натискає кнопку **Start**.
2. Він бачить 3D-планету (Місяць або Марс) з точками, де розташовані об'єкти.
3. Камера плавно підлітає до обраної точки.
4. З'являється вікно з описом об'єкта та фото.
5. Кнопка-стрілка веде до наступного об'єкта за часом.
6. Фонова музика грає протягом усієї демо, її можна вимкнути або ввімкнути.

## Об'єкти

**Місяць:** Surveyor Landers, Apollo Lunar Modules, ALSEP Scientific Packages, Lunar Roving Vehicles.

**Марс:** Viking 1 & 2, Sojourner Rover, Spirit & Opportunity, Phoenix, InSight, Ingenuity.

## Структура проєкту

| Файл | Призначення |
| `main.py` | запуск програми, головний цикл |
| `menu.py` | стартове меню |
| `scene.py` | 3D-сцена: планета, зорі, камера |
| `landmark.py` | дані про космічні об'єкти |
| `landmarkUI.py` | вікно з описом об'єкта та кнопка далі |
| `timeline.py` | хронологічний порядок об'єктів |
| `events.py` | обробка кліків та клавіш |
| `effects.py` | візуальні ефекти |
| `narration.py` | озвучка |
| `audio.py` | фонова музика |
| `config.py` | константи проєкту |
| `modules.py` | допоміжні модулі |
